# Рабочий сайт «Платформа недвижимости»

PHP 8.2+ и SQLite, без фреймворков. Спецификация: `../docs/superpowers/specs/2026-11-18-platforma-site-design.md`.

- Тесты: `php site/tests/run.php`
- Локально: `php -S localhost:8080 -t site/public site/router.php`
- Витрина для GitHub Pages: `php site/build.php` → `10_Сайт/`

PHP на этом компьютере: `C:\tools\php\php.exe`.
